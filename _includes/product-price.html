{% comment %} Resolves the price of a product for the language of the current page. Pass product=. Prices come from _data/prices.yml (keyed by translation_key); `prices` in the product front matter overrides it, and the old price_amount / price_currency fields still work for products that have not been moved yet. Sets: product_price_amount amount to show, or nil when the product has no price at all product_price_currency upper-case currency code of that amount product_price_buyable true when the amount is in the cart currency of this language product_price_json Snipcart price object listing every currency that has a price product_price_per_piece true when "per piece" should follow the price {% endcomment product_price_per_piece = true %}{% endif %} {% if pp_amounts %} {% for pp_pair in pp_amounts %} {% assign pp_code = pp_pair[0] | downcase %} {% assign pp_value = pp_pair[1] %} {% if pp_value %} {%
